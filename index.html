1. System Overview — Architecture & Data Flow

🎯 What is GrowTH?

A responsive web application that helps parents track child growth, screen for puberty development concerns, and get AI-assisted bone age estimates from hand/wrist X-rays — all in plain, parent-friendly language.

  • Growth Tracking: Height/weight with percentile & SDS charts
  • Puberty Screening: Guided questionnaire with plain-language results
  • AI Bone Age: Upload X-ray → get estimated bone age + margin of error
  • Knowledge Hub: Articles about growth & puberty

📌 Key Facts

  • Launch Date: November 2 (fixed, no extensions)
  • Internal PM Deadline: September 19 — full system test complete
  • Budget: $0 — free/open-source tools only
  • Target Users: Parents (primary), educators (secondary)
  • Data: RSNA Bone Age dataset (~12,611 train / 1,425 validation)
  • Compliance: PDPA-aligned privacy (data minimization, account-scoped access)

📌 Lead: CaptanGuts

📊 Database Schema

  • users: id, full_name, email, password_hash, phone, terms_accepted, created_at
  • children: id, user_id (FK), name, sex, dob, relationship
  • growth_records: id, child_id (FK), date, height_cm, weight_kg, percentile, sds, bmi, guidance
  • puberty_screenings: id, child_id (FK), date, responses (JSON), result_summary, action
  • bone_age_predictions: id, child_id (FK), date, image_path, predicted_months, margin_error, model_version
  • articles: id, title, topic, content, attribution
  • growth_reference: sex, age_months, L, M, S (for LMS method)

🔒 Security & Privacy (PDPA-aligned)

  • Data Minimization: Only collect what's needed (name, email, child data)
  • Password Hashing: bcrypt (never store plain text)
  • JWT Sessions: Short-lived tokens with refresh
  • Account Scoping: All child_id queries filtered by user_id (FR-24)
  • X-ray Storage: Encrypted at rest, accessible only to owner
  • Privacy Notice: Shown before registration (FR-2)
  • Data Deletion: Document what to delete on user request

6. AI Bone Age Prediction Model (Deliverable D4)

📌 Lead: CaptanGuts

🧠 Model Architecture

  • Backbone: EfficientNet-B0 (pretrained on ImageNet)
  • Input: 224×224×3 (hand/wrist X-ray)
  • Auxiliary Input: Sex (0/1) — concatenated after GAP
  • Regression Head: 1280+1 → 256 → 128 → 1 (bone age in months)
  • Framework: PyTorch
  • Transfer Learning: Fine-tune last layers

📊 Dataset: RSNA Pediatric Bone Age

  • Training: 12,611 images
  • Validation: 1,425 images
  • Labels: Bone age (months) + sex
  • Age Range: 1 – 228 months (~0–19 years)
  • Mean Age: ~127 months (~10y 7m)
  • Sex Balance: Slight male majority (~1,000 more)
  • Image Sizes: Varying → resized to 224×224

📈 Performance & Evaluation

Primary Metric: MAE (Mean Absolute Error) in months
Target: ≤ 8–10 months (comparable to RSNA challenge)
Secondary: MSE, R², accuracy within ±12 months

Preprocessing: Resize 224×224, normalize with ImageNet mean/std, augment (rotation, flip, contrast).

Inference: model.eval() + torch.no_grad() → returns predicted months + confidence.

🔗 Integration with Backend

1. Upload Frontend sends multipart/form-data with image + child_id
2. Validate Backend checks file type (JPEG/PNG) + size (≤10MB)
3. Store Save image to object storage with unique key
4. Predict Backend calls AI service → model predicts PyTorch
5. Save Store prediction in DB with child_id, image_path, result, margin
6. Respond Return JSON with bone age, margin, disclaimer, confidence

⚠️ Model Limitations (Must be shown to user)

  • This is a screening aid, not a clinical diagnosis (FR-18)
  • Margin of error: typically ±6–10 months
  • Performance may vary by age group and sex
  • Image quality affects accuracy (blurry/rotated X-rays may reduce confidence)
  • Always consult a physician for clinical decisions
